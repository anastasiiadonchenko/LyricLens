# 🎵 LyricLens: Music Lyrics Web Application

## 🌟 Project Overview
LyricLens is a modern, mobile-friendly web application for exploring music lyrics with an intuitive and responsive interface.

## ✨ Key Features
- Full song lyrics display
- Responsive mobile design
- Audio and video player integration
- Dark-themed modern UI
- Interactive song exploration

## 🛠 Technologies
- HTML5
- Tailwind CSS
- Font Awesome
- Responsive Web Design

## 📦 Project Structure
lyric-lens/
│
├── index.html             # Original index file
├── modern-index.html      # Modern responsive version
│
├── images/                # Image assets
│   └── 5265761-200.png    # Favicon or logo
│
├── audio/                 # Audio files
│   └── song.mp3           # Music track
│
└── video/                 # Video files
    └── music-video.mp4    # Music video

## 🚀 Quick Start
1. Clone repository
2. Open `modern-index.html`
3. Ensure media files are in correct directories

## 🎨 Customization
- Easily modify colors with Tailwind CSS
- Replace media files with your content

## 🌐 Compatibility
- Works on desktop and mobile browsers
